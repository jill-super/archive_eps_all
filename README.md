## Overview
This release bundles 17 Nexteer Automotive Electric Power Steering (EPS) project archives. Each package contains source code, documentation, models, or requirements where applicable. The collection covers ECU firmware, platform-specific adaptations, model-based engineering, and validation assets for leading automotive OEMs.

## Thematic Groups
- **Platform-specific EPS firmware**: RH850 and TMS570 software for BMW, Ford, GM, Fiat, Chrysler, PSA and Volkswagen.
- **Architectural and model-based assets**: Software architecture documentation and Simulink design packages.
- **Test, requirements and documentation**: Validation configurations, requirements files, and supporting EPS documentation.
